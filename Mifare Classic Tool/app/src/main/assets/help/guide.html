User Guide

راهنمای کاربر

0. General

۰. کلیات

The app works with MIFARE Classic tags via NFC. Hold the tag against the back of the phone until the app reacts. All keys and data are hexadecimal.

If the tag is lost during an operation the app shows an error; just re-tap the tag and retry.

این برنامه با تگ‌های MIFARE Classic از طریق NFC کار می‌کند. تگ را تا واکنش برنامه به پشت گوشی نزدیک نگه دارید. همه‌ی کلیدها و داده‌ها هگز هستند.

اگر وسط کار تگ جدا شود برنامه خطا نشان می‌دهد؛ کافی است تگ را دوباره نزدیک کنید و تلاش مجدد کنید.

1. Read Tag

۱. خواندن تگ

  1. Tap Read Tag on the main screen.
  2. Hold the tag near the phone.
  3. The app authenticates each sector with the keys it knows (key files) and reads the data blocks.
  4. Choose a file name and save the dump (.dump) and/or the key map (.keys).
If some sectors stay locked, the app still reads what it can — locked blocks appear as --- in the dump.
  1. روی صفحه‌ی اصلی خواندن تگ را بزنید.
  2. تگ را نزدیک گوشی نگه دارید.
  3. برنامه هر سکتور را با کلیدهایی که می‌شناسد (فایل‌های کلید) احراز و بلوک‌های داده را می‌خواند.
  4. نام فایل را انتخاب کنید و دامپ (.dump) و/یا نگاشت کلید (.keys) را ذخیره کنید.
اگر بعضی سکتورها قفل باشند، برنامه آنچه می‌تواند را می‌خواند — بلوک‌های قفل به‌صورت --- در دامپ دیده می‌شوند.

2. Write Tag

۲. نوشتن روی تگ

  1. Tap Write Tag, then choose the dump file to write.
  2. Select the sectors/blocks to write (or write everything).
  3. Hold the tag near the phone and confirm.
Writing wrong data can damage the tag. Blocks containing --- (unknown data) are skipped automatically.
"Factory Format" tries to restore the tag to its delivery state.
  1. نوشتن روی تگ را بزنید، سپس فایل دامپ موردنظر را انتخاب کنید.
  2. سکتورها/بلوک‌های موردنظر را انتخاب کنید (یا همه را بنویسید).
  3. تگ را نزدیک گوشی نگه دارید و تأیید کنید.
نوشتن داده‌ی اشتباه می‌تواند به تگ آسیب بزند. بلوک‌های دارای --- (داده‌ی ناشناخته) به‌صورت خودکار رد می‌شوند.
«فرمت کارخانه» تلاش می‌کند تگ را به حالت تحویل برگرداند.

3. Edit Tag Dump & Edit Key File

۳. ویرایش دامپ تگ و فایل کلید

  • Edit/Analyze Dump File — view and edit a .dump offline (hex editor per block). Useful to inspect or fix dumps without a tag.
  • Edit/Add Key File — manage .keys files: add, remove, deduplicate keys. These files are used by Read/Write/Brute Force.
  • ویرایش/تحلیل فایل دامپ — مشاهده و ویرایش آفلاین .dump (ویرایشگر هگز برای هر بلوک). برای بررسی یا اصلاح دامپ بدون تگ مفید است.
  • ویرایش/افزودن فایل کلید — مدیریت فایل‌های .keys: افزودن، حذف و حذف تکراری‌ها. این فایل‌ها در Read/Write/Brute Force استفاده می‌شوند.

4. Tools

۴. ابزارها

  • Tag Info — shows UID, SAK, ATQA, ATS, memory layout and guessed tag type.
  • Clone UID — clones the UID to "magic tags" (2nd gen) that allow writing block 0.
  • Diff Tool — compares two dumps and highlights differences.
  • Access Condition Tool — decodes/encodes the access bits of sector trailers and data blocks.
  • Value Block Tool — decodes/encodes value blocks as integers.
  • BCC Calculator — computes the BCC byte of block 0.
  • UID Log — history of UIDs seen by the app.
  • Data Conversion — converts between hex/bin/dec/ASCII.
  • Import/Export — converts dumps/keys between formats (.mct, .keys, .bin/.mfd/.dump, .eml, .json) and backup/restore.
  • اطلاعات تگ — نمایش UID، SAK، ATQA، ATS، ساختار حافظه و نوع حدسی تگ.
  • Clone UID — کلون UID روی «تگ‌های جادویی» نسل ۲ که اجازه‌ی نوشتن بلوک ۰ می‌دهند.
  • ابزار Diff — مقایسه‌ی دو دامپ و نمایش تفاوت‌ها.
  • ابزار Access Condition — رمزگشایی/رمزگذاری بیت‌های دسترسی sector trailer و بلوک‌های داده.
  • ابزار Value Block — رمزگشایی/رمزگذاری value block به‌صورت عدد صحیح.
  • محاسبه‌گر BCC — محاسبه‌ی بایت BCC بلوک ۰.
  • گزارش UID — تاریخچه‌ی UIDهای دیده‌شده توسط برنامه.
  • تبدیل داده — تبدیل بین hex/bin/dec/ASCII.
  • Import/Export — تبدیل دامپ/کلید بین فرمت‌ها (.mct, .keys, .bin/.mfd/.dump, .eml, .json) و پشتیبان/بازیابی.

5. Brute Force Keys

۵. Brute Force کلیدها

Tries every key in a bounded range (or every key in selected key files) against the sectors you choose, shows the keys that work and saves them to a .keys file.

Settings

  • Key Source — Key Range: enter start/end as hex keys (up to 12 digits, e.g. 000000000000–000000000059). Key File: pick one or more .keys files (tap "Choose Key File" several times to add more; long-press the file list to clear it).
  • Key Type — test Key A, Key B, or both.
  • Keys/sec — limits how many keys are tried per second. 0 = maximum speed. Lower values reduce NFC/phone load and heat.
  • Sectors —
    • All sectors — every sector of the tag.
    • Range — a contiguous sector range (From–To).
    • Pick sectors — tick individual sectors (0–39), e.g. 1, 2, 3, 7, 9. Only the ticked sectors are tested — gaps are skipped.
    In Pick sectors mode, long-press a sector to cycle its key type: Both → Key A → Key B → Both (the letter appears next to the sector number).

During the scan

  • The status line shows the current sector, key index and number of keys found.
  • Every sector that yields keys is appended to the Found keys log (S07 A=… B=…).
  • Pause suspends the scan instantly (works even inside a sector); Resume continues.
  • Cancel aborts the scan.

If the tag disconnects

Keys found so far are kept in memory. A dialog offers: Resume scan (waits for the tag, reconnects and continues with the remaining sectors — finished sectors are not retested), Save keys or Discard.

After the scan

You are asked for an output file name before scanning starts. Empty = new; if the file exists the app uses new1, new2, … Found keys are shown and saved as .keys.

Brute force on a large range takes a long time — each key needs an NFC authentication. Use a small range or a low Keys/sec value on hot devices.

هر کلید داخل یک بازه‌ی محدود (یا هر کلید داخل فایل‌های کلید انتخابی) را روی سکتورهایی که انتخاب می‌کنید امتحان می‌کند، کلیدهای درست را نشان می‌دهد و در یک فایل .keys ذخیره می‌کند.

تنظیمات

  • منبع کلید — بازه‌ی عددی: ابتدا و انتها را به‌صورت کلید هگز وارد کنید (حداکثر ۱۲ رقم، مثلاً 000000000000 تا 000000000059). فایل کلید: یک یا چند فایل .keys انتخاب کنید (برای افزودن فایل بیشتر چند بار «انتخاب فایل کلید» را بزنید؛ long-press روی لیست فایل‌ها آن را پاک می‌کند).
  • نوع کلید — تست Key A، Key B یا هر دو.
  • کلید در ثانیه — محدودیت تعداد کلیدهای تست‌شده در ثانیه. ۰ = حداکثر سرعت. مقادیر کمتر بار NFC و گرم شدن گوشی را کم می‌کنند.
  • سکتورها —
    • همه سکتورها — همه‌ی سکتورهای تگ.
    • بازه — یک بازه‌ی پیوسته‌ی سکتور (از–تا).
    • انتخاب سکتور — تیک زدن سکتورهای تکی (۰ تا ۳۹)، مثلاً ۱، ۲، ۳، ۷، ۹. فقط سکتورهای تیک‌خورده تست می‌شوند — شکاف‌ها رد می‌شوند.
    در حالت انتخاب سکتور، long-press روی یک سکتور نوع کلیدش را می‌چرخاند: هر دو → Key A → Key B → هر دو (حرف کنار شماره‌ی سکتور دیده می‌شود).

حین اسکن

  • خط وضعیت، سکتور فعلی، ایندکس کلید و تعداد کلیدهای پیداشده را نشان می‌دهد.
  • هر سکتوری که کلید بدهد در لاگ کلیدهای پیداشده اضافه می‌شود (S07 A=… B=…).
  • توقف اسکن را فوراً معلق می‌کند (حتی داخل یک سکتور هم کار می‌کند)؛ ادامه آن را از سر می‌گیرد.
  • لغو اسکن را متوقف می‌کند.

اگر تگ قطع شود

کلیدهای پیداشده تا آن لحظه در حافظه می‌مانند. یک دیالوگ پیشنهاد می‌دهد: ادامه اسکن (در انتظار تگ می‌ماند، وصل می‌شود و فقط سکتورهای باقی‌مانده را ادامه می‌دهد — سکتورهای تمام‌شده دوباره تست نمی‌شوند)، ذخیره کلیدها یا صرف‌نظر.

بعد از اسکن

قبل از شروع اسکن نام فایل خروجی پرسیده می‌شود. خالی = new؛ اگر فایل وجود داشته باشد برنامه new1، new2 و… استفاده می‌کند. کلیدهای پیداشده نمایش داده و به‌صورت .keys ذخیره می‌شوند.

Brute Force روی بازه‌ی بزرگ زمان زیادی می‌برد — برای هر کلید یک احراز هویت NFC لازم است. روی دستگاه‌های داغ از بازه‌ی کوچک یا مقدار کم Keys/sec استفاده کنید.

6. Preferences

۶. تنظیمات

  • Language — switch between English, فارسی and other languages. Applies immediately.
  • Theme — dark / light / follow system.
  • Autostart if tag detected — starts the app automatically when a MIFARE Classic tag is presented.
  • Retry authentication — retries failed authentications (helps some tags/devices, slows operations).
  • Auto reconnect — reconnects automatically if the tag is lost during key mapping.
  • Custom sector count — override the detected sector count (e.g. 16 for 1K tags).
  • زبان — تغییر بین English، فارسی و زبان‌های دیگر. بلافاصله اعمال می‌شود.
  • تم — تیره / روشن / مطابق سیستم.
  • اجرای خودکار با شناسایی تگ — با نزدیک کردن تگ MIFARE Classic برنامه خودکار اجرا می‌شود.
  • تلاش مجدد احراز هویت — تلاش مجدد احرازهای ناموفق (به بعضی تگ‌ها/دستگاه‌ها کمک می‌کند، عملیات را کند می‌کند).
  • اتصال مجدد خودکار — اتصال خودکار اگر تگ در حین نگاشت کلید گم شود.
  • تعداد سکتور سفارشی — بازنویسی تعداد سکتور شناسایی‌شده (مثلاً ۱۶ برای تگ 1K).

7. Notes & Warnings

۷. نکات و هشدارها

  • Keep the tag steady and close to the antenna area during operations.
  • Never write to sector trailers or block 0 unless you know exactly what you do — wrong access conditions can permanently lock a tag.
  • Standard keys (FFFFFFFFFFFF, 000000000000, …) are tested first for speed.
  • For Crypto1 attacks (nested/darkside) a Proxmark3 or similar hardware is required — this app works through the standard Android NFC API only.
  • در حین عملیات تگ را ثابت و نزدیک ناحیه‌ی آنتن نگه دارید.
  • هرگز روی sector trailer یا بلوک ۰ ننویسید مگر اینکه دقیقاً بدانید چه می‌کنید — access condition اشتباه می‌تواند تگ را برای همیشه قفل کند.
  • کلیدهای استاندارد (FFFFFFFFFFFF، 000000000000، …) برای سرعت اول تست می‌شوند.
  • برای حملات Crypto1 (nested/darkside) سخت‌افزار Proxmark3 یا مشابه لازم است — این برنامه فقط از API استاندارد NFC اندروید استفاده می‌کند.
